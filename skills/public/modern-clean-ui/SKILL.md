# Modern Clean UI

Use this skill to implement polished, minimal UI with strong UX consistency.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide icons
- Framer Motion (subtle only)

## Design Rules
- Use a neutral palette with one accent color.
- Keep generous whitespace and minimal borders.
- Use consistent radius (10–14px) and soft shadows.
- Use at most two font weights per screen.
- Keep strong visual hierarchy and low noise.
- Ensure accessibility: contrast, focus rings, keyboard navigation.
- Keep motion subtle and quick (150–220ms).

## Component Conventions
- Prefer composable primitives.
- Keep button/input states explicit (default/hover/focus/disabled/error).
- Use clear empty/loading/error states for data views.
- Keep forms short, grouped, and validated inline.

## Layout Conventions
- Mobile-first responsive design.
- Predictable spacing scale and container widths.
- Avoid visual clutter; remove non-essential decorations.
