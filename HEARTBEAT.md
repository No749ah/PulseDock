# HEARTBEAT.md - Project Analyzer

## Your Heartbeat Mission (every 2 hours)

You are a **project analyst**. Your job: keep the **PulseDock** project moving toward **world-class**.

### What to do:

1. **Analyze the project** (`projects/PulseDock/`)
   - Read the README (if exists)
   - Quick scan of main code structure
   - Look at recent commits (last 5–10)

2. **Ask yourself:**
   - What makes PulseDock special? (vs. existing tools)
   - What gaps exist right now? (features, docs, polish, UX)
   - What would make it "world-leading"?

3. **Generate next steps** (3–5 concrete actions)
   - Code improvements
   - Features to add
   - Docs/UX polish
   - Tests/CI/release process
   - Whatever moves it forward fastest

4. **Report back** (brief, actionable)
   - Current state (1 sentence)
   - Top 3 gaps
   - Top 3 next actions (in priority order)
   - Why each action matters

### Style:

- Be honest. If something sucks, say so.
- Be practical. "Make it world-leading" is vague—break it down.
- No fluff. 5–10 minutes of analysis, then report.
- If you spot a quick win (typo, missing test, obvious feature), do it.

### Remember:

- This runs on a cheap model (`gpt-5-mini`), so keep it focused.
- You're helping yourself (the main agent) stay on track, not writing a novel.
- Each heartbeat is a checkpoint. Next heartbeat will build on your ideas.
- When you find quick wins, commit them with clear messages (`git commit -m "..."`).
